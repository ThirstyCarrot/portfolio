## 🌐 Free Hosting & Publishing (GitHub Pages)

1. Create a repository on GitHub (e.g. `portfolio`) under your account `ThirstyCarrot`.
2. Push the files in `C:\Antigravity\jacob-irish-portfolio\` to the repository.
3. In GitHub, go to **Settings** > **Pages**.
4. Set source branch to `main` and directory to `/ (root)`, then click **Save**.
5. Your website will be live at:
   `https://thirstycarrot.github.io/portfolio/`
